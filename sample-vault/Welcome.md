# Welcome to Quire

Quire is a **fast, local-first** Markdown notepad. Your notes are plain `.md` files in this folder — open them with anything, sync them with anything.

## Try these
- [ ] Press `Ctrl+P` to jump to any note, `Ctrl+K` for every command
- [ ] Type `@tomorrow` then space — it becomes a link to a daily note
- [ ] End a line with `=` and press Enter: 1200 * 12 =
- [ ] Rename a note with `F2` — every [[Rope Notes|link to it]] is updated
- [x] Write in plain Markdown, see it styled as you type

## Linking
Link notes with `[[double brackets]]`, like [[Quire Roadmap]] or [[Reading/How Editors Store Text]]. The **Insights** panel on the right shows backlinks, related notes and *unlinked mentions* — for example this sentence mentions Rope Notes without linking it.

> Tags like #quire and nested ones like #reading/cs organise notes without folders.

| Shortcut | Action |
| --- | --- |
| Ctrl+E | Toggle preview |
| Ctrl+L | Toggle checklist |
| Ctrl+Shift+T | Format table |

==Highlights==, ~~strikethrough~~, `inline code`, and math like $e^{i\pi}+1=0$ all work.

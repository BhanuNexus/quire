# Getting help

- **How do I…?** Check the [README](README.md) first, then ask in [Discussions → Q&A](https://github.com/BhanuNexus/quire/discussions/categories/q-a).
- **Something's broken:** open a [bug report](https://github.com/BhanuNexus/quire/issues/new?template=bug_report.yml) with your OS, Quire version (Settings → About) and steps to reproduce.
- **Feature idea:** start in [Discussions → Ideas](https://github.com/BhanuNexus/quire/discussions/categories/ideas), so others can weigh in before it becomes an issue.
- **Security issue:** see [SECURITY.md](SECURITY.md). Don't post it publicly.

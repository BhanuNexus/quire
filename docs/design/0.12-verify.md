## Deferred

- **macOS and Windows file association for `.md`.** Needs Apple events (`application:openURLs:`) and registry keys in the installer; cannot be tested on this machine. Opening with a path argument works on all systems.
- **Typed links from locked notes in the graph** are not shown (the graph never reads locked notes).
- **A default for new vaults' preferences** (item 3): `prefs-copy` covers copying; a template vault is a later step.

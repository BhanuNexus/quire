# 0.14 health: the foundations

What the foundations team of the 0.14 codebase-health pass changed, and
what it left. Items are those of the plan (`codebase-health-2026-11.md`,
items 6 and 7, defects D2, D3 and D8) and of the architecture report
(items 2, 4, 7 and 9). No feature changed; where behaviour changed, a copy
was wrong, and each such change is listed under "Behaviour changes" with
its test.

## `quire-base`: one way to do each risky job

A new crate at the bottom of the graph (layer 0), with no workspace
dependencies. Its header says what belongs there: stateless,
dependency-light helpers that several crates need done one way. Nothing
that knows about notes, vaults, sync, settings or the UI; nothing with
state. Its third-party dependencies (`tempfile`, `getrandom`, `sha2`,
`chrono`, and `ureq` behind `net`) were all in the tree already.

| Module | What | Replaces |
|---|---|---|
| `fs` | `write_atomic(path, bytes, Options)`, `write`, `write_new_private`, `replace_file`, `Prepared`, `sweep_leftovers`, the busy-file retry | `quire_vault::replace_file` and its retry, `quire_app::atomic::{write, write_new_private}`, `quire-sync/src/fsx.rs`, 9 hand-written temp-file-and-rename writers |
| `rand` | `fill`, `bytes::<N>()`, both `#[must_use]` and returning `NoRandomness` | 13 `getrandom::fill` calls with 5 error policies |
| `path` | `Rule::{NoteFile, VaultFolder, ViewFolder, PlainNote, BucketPrefix, HideEntry, InsideRoot}`, `leaves_root`, `clean_import_entry` | 10 of the 11 path checks the architecture report lists |
| `enc` | `percent_decode_{strict, lossy, bytes}`, `percent_encode`, `escape_html`, `hex`, `unhex`, `sha256_hex` | 8 decoders, 5 encoders, 2 HTML escapers, hex and SHA-256 copies |
| `recovery` | the recovery-key codec | `quire_sync::RecoveryKey`'s codec (now a wrapper) |
| `time` | `now_ms`, `parse_ymd`, `parse_ymd_prefix` | 8 `now_ms` copies, 14 `YYYY-MM-DD` parses |
| `net` (feature) | `config`/`agent(purpose, Timeouts, Redirects)` | 7 HTTP client setups |

The old public paths stay as re-exports (`quire_vault::replace_file`,
`quire_app::atomic::{write, write_new_private}`,
`quire_markdown::render::escape_html`, `quire_pdf::sha256_hex`,
`quire_sync::compact::sha256_hex`, `quire_app::history_ops::now_ms`).

### The atomic writer

One implementation: `Prepared` writes a temporary file beside the
destination (made new, 0600 when private, flushed when durable), and
renames it into place with the Windows busy-file retry, removing it if
anything fails. `write_atomic` is `Prepared::new` plus `place`.
`Storage`'s vault writes keep their own temporary file (`tempfile`'s
`.tmp…` names, which history skips as writes in flight), their
locked-folder check and their one-write-at-a-time loop, and hand the
rename and the clean-up to `Prepared::adopt` and `try_place`.

`Options` names the three switches: `STATE` (flushed, folders made),
`SECRET` (the same, 0600), `EXISTING_FOLDER` (a shared sync folder: a
missing folder was removed on purpose and is not made again), each
`.lazy()` without the flush. Temporary files are
`.<name>.<16 hex>.tmp` (hidden; `sweep_leftovers` removes old ones).

### The path rules

Where the ten copies disagreed, each caller now names the rule it needs:

| Caller | Rule | Changed |
|---|---|---|
| `quire_agent::canonical_path` (agents, the web app) | `NoteFile` | no |
| `quire_vault` `LocalFs::abs` | `InsideRoot` | no |
| `quire_sync::remote::clean_prefix` | `BucketPrefix` (after trimming) | no |
| `quire_web::paths::normalize_hidden` | `HideEntry` (after trimming, NFC, lower case) | no: stricter would drop entries and show more |
| `quire_import` archive entries | `clean_import_entry` | no |
| `quire_vault::lock::refuse_to_lock` | `VaultFolder` | **yes**: a drive (`C:/x`) and control characters are refused too |
| `quire_app::vault_sync` `Selection::new` (folders to sync) | `VaultFolder` (after trimming) | **yes**: a drive is refused too |
| `quire_app::tasks_state::safe_new_note_folder` | root, or `ViewFolder` | **yes**: an empty segment (`a//b`) is refused too |
| `quire_app::import_run` undo | `PlainNote` | **yes**: a path with a control character is left alone |
| `quire_app::vault_sync` store, `.quire/shared/…` from sync | `PlainNote`, and no `..` anywhere (as before) | **yes**: control characters, `\`, empty segments and a drive are refused too |

No check was loosened. Where a copy was stricter for a reason it kept
that as its own rule: `ViewFolder` refuses any `:` (the 0.11 security
review's choice for a folder named by a shared view), and the shared
settings check keeps its "no `..` anywhere". `VaultFolder` and `PlainNote`
accept a `:` inside a name (`Q1: Plans`, as LocalFs and macOS/Linux do)
and refuse it only as a drive; refusing every `:` would have stopped a
person from locking or syncing such a folder. `PlainNote` is
`VaultFolder`'s check under its own name: undo trashes files without
asking, from a record that could have been edited, so even `.quire` is
refused (the agent rule allows it).
`import_run.rs:175` (`folders_to_create`) is not a safety check (it skips
paths the import itself refuses) and stays as it is.

### Small helpers

- **Percent-decoding.** Strict where a path or name results (the web app,
  WebDAV listings, links copied as HTML); lossy where text is shown or
  matched (Markdown links, the agent, importers); raw bytes for the web
  importer; the typesetter keeps its "whole input if not UTF-8".
- **Percent-encoding.** Every copy used RFC 3986's unreserved set plus a
  few bytes to keep: `percent_encode(s, keep)` gives the same output.
- **HTML escaping.** `quire-markdown` and the OAuth pages use the shared
  one. Not moved, because they differ on purpose or the bytes are a file:
  `quire-canvas` `excalidraw::esc` and `quire-app` `remind_bg::xml` (no
  `'`: their output is an SVG and job files, whose bytes would change),
  `quire-agent` `fence::escape_attr` (folds newlines on purpose), the
  sync mock server (test code).
- **Dates.** `parse_ymd` (the whole string, for a date typed in a field)
  and `parse_ymd_prefix` (the first ten bytes, for front matter that may
  carry a time); each site keeps the form it had. Not moved:
  `quire-import` `obsidian/expr.rs` (its own date grammar).
- **Hex.** `quire-web` `asset_version` keeps its five-byte hash (a short
  fingerprint, not a hex helper).

### The HTTP client builder

`quire_base::net` sets the TLS roots (the platform verifier), the user
agent (`Quire/<version> (+purpose)`), the timeouts given, and
`http_status_as_error(false)`; the redirect policy is an argument. It sits
behind the `net` feature: only crates that P6 allows to reach the network
turn it on (`quire-sync` `http`, `quire-import`, `quire-intel`
`remote-llm`, `quire-ai` `client`, `quire-app` `update-check`), so the
sync server and the AI engine are built without `ureq` as before. Those
crates keep their own `ureq` dependency for its types, so cargo-deny's
`ureq` wrapper list keeps naming every crate with network code; it needs
`quire-base` added to it (`deny.toml` is the docs team's).

| Client | Redirects | Changed |
|---|---|---|
| model downloads (`quire-ai`) | follow 10 | no |
| update check (`quire-app`) | follow 10 | no (keeps `http_status_as_error(true)`) |
| sync server (`quire-sync` `http`) | follow 10 (ureq drops `Authorization`) | no |
| S3/WebDAV (`quire-sync` `remote`) | refuse | no |
| web capture (`quire-import`) | refuse (followed by `fetch`, checked) | no |
| LLM providers (`quire-intel`) | follow 10 | **yes**: now sends `Quire/<version> (+llm)` |

## Behaviour changes (each a copy that was wrong)

Each is named in its commit message, with its test.

- **Random bytes (D2).** See Defects.
- **Path rules.** The four stricter callers in the table above.
- **`%+1`** is no longer an escape in any decoder (all eight read it as
  U+0001: `u8::from_str_radix` takes a sign); `unhex` likewise refuses a
  sign. Test: `quire_base::enc` tests, on the differential inputs.
- **Writers.** The nine hand-written writers had a fixed or pid-named
  temporary file, mostly no flush, and three dropped errors or left the
  temporary file behind; they now flush, use a random name and clean up.
  The sync folder's writer gained the Windows busy-file retry; app state
  writes flush their folder after the rename (Unix). Five more plain
  `fs::write`s became atomic: a published site, `agent skill install`,
  `notes html`, the eval report, the desktop's sample vault. The CLI's
  `notes pdf` no longer falls back to a copy that can leave half a file.
- **LLM requests** name the client (`Quire/<version> (+llm)`).
- **Threads.** 45 unnamed threads are named; a spawn failure still panics
  as before (`.expect`).

## Defects

- **D2.** Four places went on with all-zero bytes when the random source
  failed: the XChaCha nonce of sealed MCP request states, the consent
  code (`AAAA-AAAA`), consent ids and token families. All 13 random sites
  now use `quire_base::rand`, whose result is `#[must_use]`.
  `Sealer::seal` returns the error and the write tools answer
  `no_randomness` without writing; consent and token creation fail.
  `quire_base::rand::failing` makes the source fail on one thread, so
  tests can show it: `mrtr`, `tokens` and `consent` tests.
- **D3.** Reproduced first. With `Daily/` locked, its key file removed
  and a plain `Daily/New.md` tagged `#x`, `quire-cli tags <vault> rename x
  y --write` rewrote `Daily/New.md` in plain and kept its earlier version
  in history. `tags`/`props --write` and `lint` now open the vault
  through `secure_state::open_vault`: the folder stays locked, its notes
  are left out, the rest of the vault changes. Test: `lock_cli`
  `a_locked_folder_whose_key_file_is_missing_stays_locked_for_tag_and_property_changes`.
- **D8.** `ureq` is a dev-dependency of `quire-mcp`.

## `clippy.toml`

The proposed file of `lints.md`, pointing at `quire-base`:
`std::fs::{rename, write, File::create}`, `tempfile` `persist*`,
`Vault::open_local`, `YamlLoader::load_from_str`, `ureq` agents and global
calls, `Command::new`, `process::exit`, `getrandom::fill` and
`std::thread::spawn`. Only `getrandom::fill` has a `replacement`
(`quire_base::rand::fill` takes the same arguments); the others' callers
differ in signature or are methods. Not in the file: the wall clock,
`std::env::var` and `Result::unwrap_or_default` (the ratchet, later).

- Tests: `#![cfg_attr(test, allow(...))]` at each crate root and
  `#![allow(...)]` in each file under `tests/` and `benches/`.
- Modules that own a raw call say so once (`#![expect]`): `quire-base`
  `fs` and `rand`, `quire-app` `git` and `remind_bg`, `quire-vault`
  `storage`, `quire-cli` `bench`, two `examples/`.
- Other legitimate calls say why on the call (`#[expect]`): the two
  `open_vault` gates, `net::config`, `load_yaml`, folder swaps in the sync
  folder and mirror, the sync state renamed with its selection, a damaged
  timer file moved aside, model `.part` downloads and the engine unpack,
  the AI engine, ACP agent, `stty` and memory-size spawns, the fake
  engine's `exit`.

|---|---|---|
| `disallowed_methods` violations (clippy, full edition) | 90, and 45 unnamed threads | **0** (full and Lite, `--features eval`, `quire-pdf --features render`) |
| hand-written temp-file-and-rename writers | 9, and `fsx.rs` | 0 |
| `fs::rename` / `fs::write` / `File::create` calls | 23 / 19 / 4 | 12 / 1 / 2, each under an `#[expect]` with its reason |
| `getrandom::fill` calls | 13 | 1 (`quire_base::rand`) |

Not checked: Windows- and macOS-only code paths (no cross toolchain

## The `quire-vault → quire-sync` edge

Removed. Its only use was the recovery-key codec of a locked folder's
key; the codec moved unchanged to `quire_base::recovery`, which
`quire_sync::RecoveryKey` wraps and `quire_vault::lock::FolderKey` calls.
The 0.12 vector is pinned in all three crates. A change in `quire-sync`
now rebuilds 7 workspace crates instead of 16 (`cargo tree --invert
quire-sync -e normal,build`); no longer `quire-vault`, `quire-spell`,
`quire-import`, `quire-index`, `quire-intel`, `quire-agent`, `quire-ai`,
`quire-ai-engine` or `quire-pdf`.

## Left as it is

- `quire-canvas` `excalidraw::esc` and `quire-app` `remind_bg::xml`
  (HTML escaping without `'`): their output bytes are an SVG and job
  files. `quire-agent` `fence::escape_attr` folds newlines on purpose.
- `quire-import` `obsidian/expr.rs` dates (its own grammar).
- `quire-web` `asset_version` (a five-byte fingerprint).
- Retry loops, id formats and settings loaders (different jobs; the
  architecture report agrees).
- `deny.toml` (the docs team's): its `ureq` wrapper list, when added,
  needs `quire-base`; `quire-mcp` can leave it (D8).

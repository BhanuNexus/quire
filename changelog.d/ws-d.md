### Added
- A short choice the first time you start Quire 0.9: no AI, a provider (Claude, OpenAI, or a server you run such as Ollama), or small models on this computer. Nothing is preselected and nothing downloads unless you ask. If you are upgrading, a card above the note offers the same choice once.
- On-device AI, for both Quire and Quire Lite: meaning search, writing help and the agent, and reading text in images and scanned PDFs, from models that download once and then work offline. They run in a separate engine process, so a model that fails or runs out of memory never takes the editor down. Each download shows its size, progress and speed, can be paused, resumed and cancelled, and is checked against a hash built into Quire. "Install from file…" installs models downloaded on another computer.
- Settings → AI, rebuilt: your provider, what runs on this computer (with Download, Pause, Delete and the engine's memory use), which model the agent panel uses, and the trust features (Ask style, citation checks, staleness, contradictions).
- The Agent panel (Ctrl+Shift+J): ask about your notes or ask for changes. It searches and reads your notes with the same tools AI apps get over MCP, shows each step, and its edits to your notes arrive as suggestions you review; it writes directly only in `wiki/`. Stop works at any moment. Ask mode only reads. It sends the open note and your selection along when you leave their chips on. Conversations are kept on this computer for 30 days and can be saved as a note.
- With a small on-device model the panel only chats about the open note; the balanced model reads notes and makes one change per message; larger and cloud models use every tool. The panel says which.
- Connect an external agent (Claude Code, Codex or another ACP agent) to the panel, after a warning that it runs with your permissions. Its edits through Quire become suggestions, and when it asks to run commands, fetch from the web or delete, the answer starts on Deny. An amber "External" label stays on the panel while it is connected.
- Ingest into wiki (command, `quire-cli ingest <vault> <note or URL>`, and the MCP prompt `quire_ingest`): a source becomes a summary page in `wiki/sources/` and concept pages in `wiki/concepts/`, every point quoting the source with a checkable citation. Points whose quote isn't in the source are left out. Links from your own notes are suggestions. On a cloud model you see the cost first. "Revert run" undoes the whole ingest.
- `wiki/index.md` lists the wiki's pages by type with a line about each, kept up to date automatically between its markers (your own text around them stays). `wiki/log.md` gets a line for each ingest, each agent run in the wiki and each batch of accepted suggestions there.
- MCP apps get Quire's built-in prompts (`quire_ingest`, `quire_lint`, `quire_answer`, `quire_maintain_index`), and `ask` in model mode uses the AI you set up in Quire.
- `quire-cli ai models|download|install|delete|engine` manages on-device models from the command line.

- Settings → "AI & search" is now Settings → AI. "Set up AI…" opens the first-run choice again.

### Added
- `quire-cli agent proposals|show|log <vault>`: list the changes AI agents suggested for review, show one with its diff, and see what agents did on this computer.
- MCP clients that speak protocol 2026-07-28 can use Quire's server (`server/discover`, tools); older clients are answered exactly as before.

### Changed
- Edits made through MCP (`quire-cli mcp --allow-write`) are recorded in version history with who made them, and in a log of agent activity in `.quire/agent/`. They can no longer write inside `.quire/`.

### Fixed
- A version saved by an AI agent is no longer replaced in history when you save the same note again within two minutes.
